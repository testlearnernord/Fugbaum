# Fugbaum

Ein kleines, direkt im Browser spielbares Bernd-Knauer-RPG.

## Spielen

`index.html` im Browser öffnen oder im Projektverzeichnis einen lokalen Server starten:

```sh
python3 -m http.server 8000
```

Anschließend `http://localhost:8000` aufrufen. Nebenjobs bringen Geld, Siege bringen
Erfahrung und Respekt. Kaufe Ausrüstung, steige in der Gang auf und gewinne fünf Kämpfe,
um den Showdown mit den Laboe Blue Brothers freizuschalten. Der Spielstand wird lokal
im Browser gespeichert; **Neues Spiel** setzt ihn zurück.
