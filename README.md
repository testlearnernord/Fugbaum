# Fugbaum

Ein kleines, direkt im Browser spielbares Bernd-Knauer-RPG.

Die Seite enthält einen quellenverlinkten historischen Hintergrund, vom Nutzer
bereitgestellte Bilder sowie eigens gezeichnete SVG-Illustrationen. Die ergänzte
Mini-Story ist ausdrücklich fiktional und keine Biografie.

## Spielen

`index.html` im Browser öffnen oder im Projektverzeichnis einen lokalen Server starten:

```sh
python3 -m http.server 8000
```

Anschließend `http://localhost:8000` aufrufen. Nebenjobs bringen Geld, Siege bringen
Erfahrung und Respekt. Kaufe Ausrüstung, steige in der Gang auf und gewinne fünf Kämpfe,
um den Showdown mit den Laboe Blue Brothers freizuschalten. Der Spielstand wird lokal
im Browser gespeichert; **Neues Spiel** setzt ihn zurück.

## Mit Bernd unterwegs

Die schematischen, frei erfundenen Karten von **Ellerbek, Wellingdorf, Gaarden
und Laboe** lassen sich zu Fuß erkunden:

- Karte anklicken oder per Tab fokussieren, dann mit **WASD oder Pfeiltasten** laufen.
- **E oder Leertaste** interagiert mit Stationen auf dem eigenen oder einem
  unmittelbar benachbarten Feld. Alternativ die Bildschirmtasten verwenden.
- **★** entdeckt eine Bild-/Spruchstation, **€** startet einen Nebenjob,
  **♥** eine Pause und **⚑** einen Kampf. Im Kampf pausieren Bewegung und Reisen.
- **↔** an den Straßenenden wechselt den Ort; die Ortsbuttons erlauben direktes Reisen.
  Die Übergänge bilden keine echten geografischen Nachbarschaften ab.
- Jede der zwölf Stationen gibt einmalig **5 XP und 5 €**. Position und Entdeckungen
  werden gespeichert; ältere Spielstände starten in Ellerbek und behalten ihren RPG-Fortschritt.

Das Viertelalbum kombiniert die vier bereits vorhandenen, vom Nutzer bereitgestellten
Fotomotive mit zwölf **eigens geschriebenen, fiktiven Spielsprüchen**.
Die Motive werden wiederverwendet; es sind keine zwölf unterschiedlichen Fotos und
keine Aufnahmen der dargestellten Orte. Die Sprüche sind **keine Zitate aus der Doku**.
Historischer Hintergrund und Quellen stehen im Spiel, getrennt von der Fiktion.
Es werden keine zusätzlichen Filmstandbilder oder längeren Filmtexte übernommen.
Quelle und Nutzungsrechte der bereitgestellten Bilder vor einer Veröffentlichung prüfen.
